# 🌌 Quantum Odyssey

Quantum Odyssey is an AI-powered learning companion built using the Caspian SDK.

## Features

- 📧 AI Email Assistant
- 💬 Discord Bot
- 🧠 AI Mentor
- 🎯 Daily Learning Missions
- 🏆 XP & Level System
- 💾 SQLite Database
- 🌍 Multi-channel Communication via Caspian

## Tech Stack

- Python
- Caspian SDK
- Featherless AI
- SQLite
- Discord API

## Running the Project

```bash
pip install -r requirements.txt
python app/main.py
```
