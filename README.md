# 🌌 Quantum Odyssey

An AI-powered learning mentor that turns studying into an interactive journey.

## 🚀 What is Quantum Odyssey?

Quantum Odyssey is an AI student mentor that helps learners study, practice, and track their progress through AI-powered conversations.

It works across multiple communication channels and combines learning tools with gamification.

## ✨ Features

- 🧠 AI Learning Mentor
- 📧 Email interaction
- 💬 Discord interaction
- 📝 AI-generated quizzes
- 🗺️ 30-day learning roadmaps
- 📚 Personalized study plans
- 🎯 Daily learning missions
- ⭐ XP and levels
- 🎖️ Achievement badges
- 🔥 Learning streaks
- 🏆 Leaderboard
- 📊 Student progress tracking
- 💾 Learning history

## 🛠️ Tech Stack

- Python
- Caspian SDK
- Featherless AI
- SQLite
- Discord
- Email
- Python-dotenv
